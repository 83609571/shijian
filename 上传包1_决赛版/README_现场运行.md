# 现场运行手册（决赛 · 郑州）

> 适用：`赣鄱智轨` 决赛版 v3.0。整套系统**离线可跑**（仿真引擎、trace、锚点台账全在本地），断网不影响演示。

---

## 一、三步启动

**Windows（组委会电脑 / 自己的笔记本）**
1. 插 U 盘，把整个项目文件夹拷到桌面；
2. 双击 **`demo.bat`**（首次运行若弹防火墙提示，点「允许」；只绑本机 127.0.0.1，点拒绝也能用）；
3. 浏览器自动打开演示台 `http://127.0.0.1:8000/stage.html`，左上三盏灯全绿即可开场。

**macOS（自己的电脑）**
1. 终端进入项目目录，执行 `chmod +x demo.command`（只需一次）；
2. 双击 `demo.command`（或在终端 `./demo.command`）；
3. 浏览器自动打开演示台。

**命令行直接跑（两系统通用）**
```bash
python3 demo.py                # 默认端口 8000，被占自动 +10
python3 demo.py --no-browser   # 只起服务不开浏览器（录屏/远程）
python3 demo.py --check        # 演示前自检，三项全 PASS 再出门
```

## 二、常见故障

| 症状 | 原因与处理 |
|---|---|
| 控制台显示「端口 8000 被占用，自动改用 8001」 | 正常行为，按打印的**实际端口**访问即可；想固定端口用 `--port 9000`。若 8000–8010 全被占，换一段 `--port 9000` |
| `demo.bat` 提示「未找到 Python」 | 电脑没装或没勾 "Add Python to PATH"。装 Python 3.9+（官网安装器勾选 PATH），或用便携版 Python 解压到项目旁，把 `python.exe` 路径加进 PATH |
| 首次运行弹防火墙 / 安全提示 | 服务只监听 127.0.0.1（不对外联网），选「允许」或「取消」都不影响本机浏览器访问；选「允许」可省得反复弹窗 |
| 断网 / Wi-Fi 掉了 | **不用管**。仿真、评分、trace 回放、锚点台账全部本地运行；④ 的评分默认走离线确定性规划器。只需确认浏览器没开「离线模式」 |
| 页面顶部出现红色「API 未连接」横幅 | api_server 没起来或被杀。回终端看报错，重新 `python3 demo.py`；恢复后**做任意一次操作**横幅自动消失 |
| 打开是空白页 / 报 404 | 确认是从项目根目录启动的（`demo.bat` 已自动定位）；不要单独双击 html 文件用 `file://` 打开——互动模块需要同源 API |

## 三、演示前检查清单（开场前 10 分钟）

- [ ] `python3 demo.py --check` 三行全 **PASS**（仿真锚点 / 通信台账 / API 自检）
- [ ] 双击启动后三盏灯全绿：版本 v3.0 / 离线可用 / API 已连接
- [ ] **关闭浏览器全部扩展**（翻译、广告拦截、隐私插件可能拦截 fetch 导致红横幅）
- [ ] 投影分辨率下按一次 `F`（大屏字号 +25%），确认后排能看清
- [ ] 过一遍四宫格：① 切一次枢纽 → ② 拉一次滑块 → ③ 点「一键对比 4G vs 5G-A」（应显示 57.8×）→ ④ 拖成本权重到 60（推荐应翻到 A）
- [ ] 「看它怎么想」选最新一条 trace 播放几步，护栏步骤三段留痕正常
- [ ] **U 盘双备份**：整个项目文件夹 + 一份录屏（断电兜底）
- [ ] 关掉无关程序（微信弹窗、系统更新）；浏览器全屏（F11）
- [ ] 记住收尾：终端 `Ctrl+C` 退出（子进程一并结束，不留孤儿进程）
