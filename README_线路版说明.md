# 赣鄱智轨 · 线路精简版（2026-10-10）

从 `GitHub发布包_v2` 复制而来，专为"只看线路"的干净展示场景裁剪。
目录结构与部署方式与发布包完全一致（bmap.html + js/ + data/ + lib/ + css/），
整目录上传 GitHub Pages 或本地 `python -m http.server` 即可运行。

## 与发布包的差异（最终状态 · 2026-10-10）

1. **四项合一 + 三合一**：「通勤层 / 旅游层 / 工作日活动模式 / 周末节假日模式」合并，
   连同「线路」「列车运行」再合并为一个「线网一张图」开关 —— 未全开 → 点击全开
   （线路+站点客流+列车动画）并回到标准江西全景视野；已全开 → 点击全关。
   线路全部统一白色（`js/config.js` 的 `COLOR.unified` 一处可改）。
2. **站点客流**：34 站青色大圆点（原始 18px 样式、统一着色）+ 站名 + 日均客流标签，
   随「线网一张图」开关联动显隐；数据来自 `data/flow_<scenario>.json` 的 stations
   （默认节假日口径，URL 加 `?flow=weekday` 切工作日）；标签按缩放分级
   （省级 Top10 → zoom≥10 显 22 站 → zoom≥11 全显 34 站）；点击圆点弹客流详情
   （含公开统计/仿真推演口径）。显隐用 show()/hide() 管理
   （BMapGL 对 Label 的 removeOverlay 不可靠，勿改回 add/remove）。
3. **齿轨爬坡段**：橙色闪烁段 + 段名标注 + 点击弹技术参数（原版效果完整恢复）。
4. **已移除**：客流热力（heatmap.js）、路段流量（flow-layer.js）、制式分段
   （system-lines.js）、百度实时路况（map-base 内置按钮）——脚本与入口均已清除。
5. **干净加载**：决策地图不随节假日场景自动开启，智能体面板初始收起；
   需要时经工具栏「决策地图·枢纽治理」或导航「智能体面板 / 应急演示」手动打开。
6. **保留**：智能体面板 / 换乘仿真 / 仿真评价指标 / 应急演示，工具栏折叠、
   地图控件开关，底图 POI 图标隐藏（DARK_STYLE）。
